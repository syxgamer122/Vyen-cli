# Local Audit Log (R2.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a local-first, tamper-evident, non-blocking JSONL audit log under `$XDG_DATA_HOME/vyen/audit/` capturing tool decisions, pairing lifecycles, and remote approvals with size rotation, zero secret leakage, and opt-out support.

**Architecture:** A standalone `src/audit.ts` module (Module #32) providing `AuditLogger`, wired into `HookBus` in `src/hooks.ts` for automated tool decision tracking and called by `PairManager` in `src/pair.ts` for pairing lifecycle events. Logs are written asynchronously off the critical path using daily JSONL rotation with a 10MB chunking limit and `VYEN_AUDIT=off` opt-out.

**Tech Stack:** TypeScript strict, Node.js (`fs/promises`, `path`), Zod schema validation, Node test runner (`node:test`).

**Spec:** [`docs/superpowers/specs/2026-10-28-audit-log-design.md`](file:///c:/Users/Admin/Downloads/Vyen-cli-main/docs/superpowers/specs/2026-10-28-audit-log-design.md)

## Global Constraints
- Target platform: Node >= 22.16, TypeScript 5.9 strict (NodeNext), Linux/Termux/Windows compatible.
- Audit write overhead: off critical path, under 1 ms per tool write (`AGENTS.md` §8.3).
- Zero secret leakage: configured API keys must never appear in any persisted audit file.
- Module count: bump from 31 to 32 modules (`src/audit.ts`), synchronized across docs and tests.
- Gate before done: `npm run lint` 0 errors, `npm run typecheck` exit 0, `npm test` 0 failures.

## Review Focus
1. Tool run emits one valid JSONL record containing duration, tokens, tool name, and decision.
2. Remote pair start, stop, and remote approval/denial write records that name the remote origin.
3. Setting `VYEN_AUDIT=off` completely disables audit logging and creates zero audit files on disk.
4. Redaction ensures configured secrets never appear in audit error fields even when child processes or tools fail.
5. Large audit volume rolls over to indexed chunk `audit-YYYY-MM-DD.1.jsonl` when exceeding the size limit.

## Scenarios & Tests

**What the user sees:** When Vyen executes tools or remote pair connections, a structured log file is automatically appended under `~/.local/share/vyen/audit/audit-YYYY-MM-DD.jsonl` without slowing down the CLI, showing exactly what tools ran, what was approved or denied, and how many tokens were consumed. Setting `VYEN_AUDIT=off` stops all logging.
