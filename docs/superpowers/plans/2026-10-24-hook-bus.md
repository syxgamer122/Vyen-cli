# Hook Bus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement R1.2 Hook Bus with lifecycle events (`SessionStart`, `SessionEnd`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PreCompact`, `Stop`), JSON stdin/stdout execution, exit code 0 (context injection) / 2 (tool denial), workspace trust hash verification, and harness integration.

**Architecture:** Create `src/hooks.ts` for hook discovery, workspace trust hashing, matcher filtering, process spawning with clean environments, and event dispatching. Extend `src/settings.ts` schema for project/user hooks. Wire `HookBus` into `src/harness.ts` (`executeBatch`, turn lifecycle) and `src/cli.ts`.

**Tech Stack:** TypeScript 5.9 strict (NodeNext), Zod, Node.js `node:child_process`, `node:crypto`, `node:test`, oxlint.

**Spec:** `docs/ROADMAP.md` R1.2, `docs/SPEC.md`.

## Global Constraints

- TypeScript 5.9 strict (NodeNext), zero lint errors (`oxlint`), clean `tsc --noEmit`.
- No new external dependencies; use Node built-ins (`child_process`, `crypto`, `fs`).
- Hook execution environment MUST never expose `VYEN_API_KEY` or sensitive credentials.
- Project hooks require workspace trust; hash must cover `.vyen/settings.json` and any referenced scripts.
- A broken or timing out hook must not crash the agent run.
- `AGENTS.md` and `tests/docs-contract.test.mjs` must remain in sync (28 source files, character budget under 24,000 with ~1,000 to spare).

## Review Focus

1. A PreToolUse hook returning exit code 2 blocks tool execution.
2. A hook returning exit code 0 can inject context via stdout.
3. A broken or timing out hook emits a warning and does not crash the agent run.
4. Project hooks require workspace trust and modifying referenced script invalidates trust.
5. Hook child processes never inherit the API key or secret credentials.

## Scenarios & Tests

**What the user sees:** when hooks are defined in `.vyen/settings.json` or user config, lifecycle events execute external scripts; a security hook can inspect tool calls and block them by exiting with code 2; context-injecting hooks can feed information into the agent prompt; untrusted or modified hook scripts trigger a trust warning before running.
